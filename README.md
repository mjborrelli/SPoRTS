Check out Methods S1 of the paper for user guides:
https://doi.org/10.1016/j.crmeth.2025.100987.

A critical note: SPoRTS is case-sensitive.

If you run into errors (or SPoRTS isn't behaving as intended),
please verify that your image naming is consistent across
experiments, and with the information entered in
`fluor_settings`/`biosensor_settings`.

Also, if using constitutive correction, ensure the naming of
cell types and fluorophores/fluorescence channels is
consistent between intensity (control) and ratio
(experimental) image sets, and between `fluor_settings` and
`biosensor_settings`.

If you'd like to use SPoRTS but you're running into
difficulties, please feel free to contact me at
mborrel2@uwo.ca with subject line "SPoRTS troubleshooting".
